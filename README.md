# Number Guessing Game in Java

This is **Task 4** of the **Tech-Driven Internship Program by Kodbud**.  
This Java console-based game challenges the user to guess a randomly generated number within a certain range.  
After each guess, the program provides hints to help the player find the correct number.

## 💡 Features
- Random number generation  
- Interactive guessing experience  
- Hints for higher or lower guesses  
- Tracks the number of attempts  

## ▶️ How to Run
1. Save the file as `NumberGuessingGame.java`
2. Open terminal and run:
    javac NumberGuessingGame.java
    java NumberGuessingGame
   
## 🧩 Concepts Used
- Random number generation using `Random` class  
- Conditional statements (`if-else`)  
- Loops for repeated guessing  
- User input handling with `Scanner` class
